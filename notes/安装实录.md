# 全新安装实录（最终复核）

日期：2026-10-29。机器：macOS arm64，Python 3.13.5。干净目录 `/tmp/weekglass-final`。从本地 git 仓库 clone 当前 `HEAD`，按 `README.md` 的“快速开始”执行，不参考开发环境。

## 1. clone

```
$ git clone -q /Users/you/NO/weekglass /tmp/weekglass-final
$ pwd
/tmp/weekglass-final
```

没有远程仓库；本地 clone 与最终交付的提交一致。

## 4. 在干净环境跑测试

README 的运行时安装不包含 pytest，直接跑会得到：

```
$ python -m pytest -q
/private/tmp/weekglass-final/.venv/bin/python: No module named pytest
```

这是预期行为，不是安装失败；开发依赖按 `docs/development.md` 安装：

```
$ python -m pip install -e '.[dev]'
...
Successfully installed iniconfig-2.3.1 packaging-26.3 pluggy-1.7.0 pygments-2.21.0 pytest-9.2.0 weekglass-0.1.0
$ python -m pytest -q
139 passed in 0.45s
```

模板随 wheel 一起可用：

```
$ python -c "import weekglass,pathlib; print(weekglass.__version__); print((pathlib.Path(weekglass.__file__).parent/'templates/report.html.j2').exists())"
0.1.0
True
```

## 5. 浏览器核对
