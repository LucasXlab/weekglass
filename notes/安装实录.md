# 全新安装实录

日期：2026-10-29。机器：macOS arm64；Python 3.13.5；干净目录 `/tmp/weekglass-clean`。按 `README.md` 的“快速开始”执行，不参考开发环境。

## 1. clone

```
$ git clone -q /Users/you/NO/weekglass /tmp/weekglass-clean
```

## 2. 按 README 安装

```
$ python3 --version
Python 3.13.5
$ python3 -m venv .venv
$ . .venv/bin/activate
$ python -m pip install -e .
...
Successfully installed MarkupSafe-3.0.4 click-8.5.0 icalendar-7.3.0 jinja2-3.1.6 python-dateutil-2.9.0.post0 recurring-ical-events-3.8.2 six-1.17.0 tzdata-2026.6 weekglass-0.1.0 x-wr-timezone-2.0.1
```

有一条警告：

```
WARNING: The directory '/Users/you/Library/Caches/pip' or its parent directory is not owned or is not writable by the current user. The cache has been disabled.
```

pip 自动禁用缓存，安装继续并成功；这不是 Weekglass 的问题，换一台缓存可写的机器不会出现。没有修改 README。

## 4. 在干净环境跑测试

```
$ python -m pip install -e '.[dev]'
$ pytest -q
114 passed in 0.52s
```

## 5. 发现并修复的问题

1. **第一次干净测试是 106 passed。** 原因是 `tests/test_suggestions.py` 没有提交，clone 只拿到已提交文件；不是安装失败。补提交 `test: 覆盖专注建议的网格、上限与排序` 后重跑 114 passed。
2. **pip 缓存权限警告。** 未修复：属于机器家目录权限，pip 已自动禁用缓存；不影响安装和运行。
3. **没有超过 5 分钟才出结果。** `pip install` 在一次会话内完成；`demo` 本机 0.13 秒。未记录安装的秒表时间，不写推测值。

## 6. 结论

README 的 clone → venv → `pip install -e .` → `weekglass demo` 路径可用；生成 5 个文件，报告无 JS/外链，375px 无水平滚动。安装路径无需修改。
