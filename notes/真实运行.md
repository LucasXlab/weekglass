## 5 类异常

### A1 网络不可用

用 `sitecustomize.py` 把 `socket.socket`、`create_connection`、`getaddrinfo` 替换为抛 `OSError`：

```
$ PYTHONPATH=/tmp/wg-nonet python -c 'import socket; socket.socket()'
OSError: network disabled for anomaly test
$ PYTHONPATH=/tmp/wg-nonet weekglass audit /tmp/wg-runs/demo/work.ics --week 2026-10-26 --json - --quiet
exit=0，JSON 可解析
```

结论：CLI 不依赖网络；不是“拔网线”测试，是更严格地把 socket 调用变成失败。

### A2 坏配置

```
$ WEEKGLASS_MIN_FOCUS_MINUTES=abc weekglass audit ...
错误[bad_config]：WEEKGLASS_MIN_FOCUS_MINUTES='abc' 不是整数。
exit=8
```

### A3 超大输入

`truncate -s 21M /tmp/wg-runs/big.ics`：

```
错误[file_too_large]：/tmp/wg-runs/big.ics 有 22020096 字节，超过 20 MB 上限。
exit=4
```

### A4 重复运行

```
$ weekglass demo --out /tmp/wg-runs/demo
错误[output_exists]：/tmp/wg-runs/demo 不是空目录；加 --force 覆盖，或换一个 --out。
exit=6
```

### A5 中断

生成 80,000 个事件的 `many.ics`（11,017,855 字节），设置 `WEEKGLASS_MAX_EVENTS=100000`，在进程运行 0.2–0.4 秒后发送 `SIGINT`：

```
poll_after 0.2 None
poll_after 0.4 None
interrupt_exit 130
stderr '已中断。\n'
output_exists False
```

结论：中断返回 130，不写半成品 HTML。

## 补充边界

| 场景 | 结果 |
|---|---|
| 空 VCALENDAR | 退出 0，零事件周报告 |
| 无建议的 `plan` | 退出 5；提示“减少会议、换一周或调低 --min-focus” |
| 不存在的文件 | 退出 3，`file_unreadable` |
| 损坏的 `.ics` | 退出 4，`invalid_ics`；错误不再回显解析器截取的原始字节 |
| 输出已存在 | 退出 6；`--force` 才覆盖 |

## 观察到但未改的行为

- `--quiet` 会同时隐藏终端摘要；需要结果时用 JSON/HTML。README 未承诺 `--quiet` 仍有摘要。
- `all_day_events=2` 是因为示例 `work.ics` 自带一个全天事件，不是重复计数。
- `plan` 先检查输出是否已存在，再判断有没有建议；因此“无建议 + 旧输出存在”会先报退出 6。该优先级已记录在 `docs/deviations.md` D-09/D-10。
