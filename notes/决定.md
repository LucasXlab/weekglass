# 关键决定

按时间顺序记录；括号内是理由。更细的偏离见 `docs/deviations.md`。

1. **项目名 Weekglass（周镜）**：英文名短、可搜索；中文名对应“照见一周”。包名 `weekglass`，命令同名。
2. **只做 CLI + 静态 HTML**：核心价值是“把一周看清楚”，不需要服务端。无账号、无端口、无数据库，安装即可用。
3. **Python 3.11+**：日历/时区库成熟，单文件分发简单；学生和开发者都能改。
4. **`.ics` 作为唯一输入**：Google/Outlook/Apple 都能导出；不做 OAuth，避免授权与隐私成本。
5. **`icalendar` + `recurring-ical-events`**：重复事件展开是最大坑，用经过测试的库，不自己写 RRULE。
6. **工作窗口默认 09:00–18:00，午休 12:00–13:00**：覆盖大多数知识工作者的默认；全部可用环境变量/CLI 改。
7. **完整专注默认 90 分钟**：低于 90 分钟难进入深度状态；`--min-focus` 可调。
8. **碎片定义**：短于 `min_focus` 的所有正长度空闲；不设“最小碎片”二次阈值，避免多重口径。
9. **全天事件默认不占用**：假期、生日、纪念日不应算忙碌；需要时 `--all-day-busy`。
10. **重复事件去重键**：`(uid, recurrence_id, start, end, summary)`；跨日历同 UID 同时间同标题合并，保留全部来源。
11. **建议按 15 分钟网格**：和日历默认粒度一致；单块 180 分钟封顶，避免建议一个“半天块”无法执行。
12. **建议评分**：长度优先，上午 +20，周二至周四 +10；不引入“精力量”之类不可测变量。
13. **生成 `.ics` 用 UTC**：避免 VTIMEZONE 兼容问题；`X-WEEKGLASS-TZ` 保留原始时区。
14. **HTML 单文件、无 JS、无外链**：报告可以被邮件/网盘转发，离线打开；CSP 防脚本。
15. **编辑式设计**：暖纸底、衬线大数字、时间带；删掉渐变/玻璃/卡片/emoji；颜色只表达类别。
16. **MIT**：本地 CLI，无网络服务；MIT 降低采用门槛。没有用 AGPL 的 copyleft 必要。
17. **不用 LLM**：数字必须可复现；避免“模型编造时间”的风险，也不需要 API key。
18. **不联网**：所有计算本地；测试替换 socket 为抛错，防止未来误加网络依赖。
19. **版本 0.1.0，本地标签 `v0.1.0`**：不 push、不发布；发布材料只写在 `launch/`。
20. **输出文件 0600（POSIX）**：日历标题/地点是隐私数据；临时文件默认权限经 `os.replace` 保留。
21. **周口径周一到周日**：ISO 周；默认只分析工作日，周末单独统计。
22. **报告事件上限 5000**：防止 HTML 过大；指标仍用全量事件，超过时提示。
23. **未知 TZID 按配置时区解释**：`icalendar` 对未知 TZID 返回浮动时间；给出 `floating_time` 提示，不静默。
24. **测试全部离线、临时目录、固定时钟**：任何环境都能复现；不依赖用户真实日历。
