## 标题

做了一个本地 CLI：把 .ics 日历变成一周碎片审计和专注计划

## 正文

我每周都有不少 30–60 分钟的空隙，但说不清这一周到底是被切碎了，还是只是会议多。云端排程工具能自动挪会议，但我不想把完整日历授权出去，也不想让工具改我的事件。

Weekglass 是一个本地命令行工具：导出一个或多个 `.ics` 文件，运行 `weekglass audit`，得到：

- 一周时间预算：可用、占用、完整专注、碎片、碎片率、最长空闲；
- 一个单文件 HTML 报告：时间带、按天表格、专注建议；
- 可选的 `focus.ics`：建议的专注块，自己确认后再导入。

它不联网、不要账号、不调用日历 API、不修改输入文件。报告是静态 HTML，没有 JavaScript。

一条命令看示例：

```
pip install -e .
weekglass demo --out weekglass-demo
```

然后打开 `weekglass-demo/report.html`。

几个默认值：工作窗口 09:00–18:00，午休 12:00–13:00，完整专注门槛 90 分钟；都能改。

已知限制：导出文件里的未知时区可能退化成浮动时间；夏令时回拨时相同 wall clock 的事件可能合并；生成的 `.ics` 用 UTC。

想听两类反馈：碎片率这个口径是否有用；“完整专注 90 分钟”是否符合你的实际安排。仓库地址发布时补。
